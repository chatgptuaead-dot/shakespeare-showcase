# 🎭 The Bard — An Interactive Shakespeare Showcase

A fully interactive, single-page tribute to William Shakespeare. No frameworks, no build step — just open `index.html`.

**[▶ Live Demo](https://chatgptuaead-dot.github.io/shakespeare-showcase/)** _(enable GitHub Pages → Settings → Pages → branch `main`)_

## ✨ Features

- **Animated hero** with a typewriter tagline and floating Elizabethan glyphs.
- **Life in Five Acts** — a clickable, expandable timeline of Shakespeare's life.
- **Plays Explorer** — filter the canon by genre and hover cards to flip them.
- **Quote Oracle** — summon random immortal quotes (try the spacebar) and copy them.
- **Insult Forge** — generate authentic Shakespearean insults from 22 × 22 × 32 word lists, and have your browser *speak* them aloud.
- **Word Coiner** — discover everyday words Shakespeare invented or popularised.
- **Bardic Quiz** — a five-question scored quiz with instant feedback.
- Extras: scroll-progress bar, gold ink-trail cursor, reveal-on-scroll animations, fully responsive, reduced-motion friendly.

## 🛠 Tech

Plain HTML, CSS, and vanilla JavaScript. Fonts from Google Fonts (Cinzel + EB Garamond). All text is public domain.

## 🚀 Run locally

```bash
git clone https://github.com/chatgptuaead-dot/shakespeare-showcase.git
cd shakespeare-showcase
open index.html      # or: python3 -m http.server 8000
```
